# Thought Leader | Thought Reader — React Website

A responsive React/Vite website for Phil Macleod / Thought Leader | Thought Reader.

## Included
- Responsive navigation and mobile menu
- Hero and service-selection pathways
- Hypnotherapy & mindset
- Mind-Body Pain Management
- Anxiety, stress & relaxation
- Executive mind coaching
- Tarot for mindfulness, readings, 1-to-1 training and workshops
- Corporate/professional workshops
- Retreat promotion
- Articles/resources area
- FAQ accordion
- Confidential enquiry form UI
- Mobile responsive styling
- Basic SEO metadata
- Wellbeing/medical disclaimer

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
```

## Before launch
1. Replace the abstract hero treatment with Phil's preferred photography if desired.
2. Connect the enquiry form in `src/main.jsx` to your CRM, email API, Formspree, HubSpot, etc.
3. Add final telephone/email details and privacy/cookie pages.
4. Update specific service/pricing information where required.
5. Point article links and retreat links at their final destinations.
